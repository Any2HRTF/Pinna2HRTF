# Pinna2HRTF

Calculate individualized HRTFs and HRIRs from pinna meshes and export them as SOFA files. Available as a macOS or Windows app and a Python CLI.

[Download](https://github.com/Any2HRTF/Pinna2HRTF/releases) · [Documentation](https://any2hrtf.github.io/Pinna2HRTF/docs/)

## Citation

Perfler, F., Thalhammer, L., & Majdak, P. (2026). [Pinna2HRTF: A Pipeline for Automatic Calculation of Head-Related Transfer Functions from Pinna Meshes](https://dael.euracoustics.org/confs/fa2026/data/articles/000324.pdf). Forum Acusticum 2026, Graz, Austria.
