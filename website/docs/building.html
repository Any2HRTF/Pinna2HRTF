Building from source

These instructions are for building the app yourself. If you only want to use it, get the installer from the download section.

Written for version 2.0. The current download is v1.1.0, so a few things may look different in your copy.

Get the source

Clone the repository and run the commands below from its root directory.

git clone https://github.com/Any2HRTF/Pinna2HRTF.git
cd Pinna2HRTF

macOS

On Apple Silicon, install Git, uv, Xcode Command Line Tools, and the Swift toolchain, then run:

bash Scripts/build_and_run.sh

This prepares external tools, builds build/release/Pinna2HRTF.app, and opens it. To build without launching:

bash Scripts/prepare_external_tools.sh
bash Scripts/build_release_app.sh

Local builds are ad-hoc signed. To create a DMG installer, run:

bash Scripts/build_release_app.sh --installer

The DMG and its SHA-256 checksum are written to dist/. The DMG is also ad-hoc signed and not notarized, so macOS may block the first launch; choose Open Anyway in System Settings → Privacy & Security. The build defaults to SDK 26.5; set PINNA2HRTF_MACOS_SDK to choose another installed SDK.

Signed and notarized distribution

Install a Developer ID Application certificate and save notarization credentials in Keychain under Pinna2HRTF-notary, then run:

bash Scripts/build_release_app.sh --distribution

Set PINNA2HRTF_SIGNING_IDENTITY to choose a certificate or PINNA2HRTF_NOTARY_PROFILE to select another Keychain profile.

Windows

Use PowerShell with the .NET 8 SDK, Git, and uv installed:

.\Scripts\prepare_windows_external_tools.ps1
.\Scripts\build_windows_port.ps1

The portable app is written to dist\windows\Pinna2HRTF.
