Getting started

Pinna2HRTF prepares one or two ear meshes, runs an acoustic simulation on them, and exports individualized HRTFs and HRIRs as SOFA files. This page walks you through a first run. The guides go deeper.

A note on versions. These pages describe version 2.0 of the app and CLI, as it is in the source. The current download is still v1.1.0, so some of what you read here may not be in your installer yet.

Before you start

You need one or two ear meshes, a project folder, an evaluation grid (the source directions), and a frequency range. For a full-head scan, first align the scan and review the extracted ears. Left and right always refer to the person being modeled.

Your first run

  1. Create a project. Choose where to save it and add your ear meshes. If you have a full-head scan, follow scan preparation first.
  2. Inspect the geometry. Check the selected ears and their orientation in Preview. Mesh2PPM prediction is optional; start with your original meshes unless you intend to use predicted geometry.
  3. Prepare the simulation. Choose the evaluation grid and frequency range in Project Settings, then run Preprocessing. Inspect the resulting geometry and source placement before starting NumCalc.
  4. Solve. Run NumCalc and follow progress in the live log. Use the technical log to investigate errors.
  5. Export. Run SOFA export and postprocessing after the simulation completes. Keep the project configuration with the results so you can identify how they were produced.

What you get. HRTFs describe how sound is filtered for each source direction. HRIRs are the corresponding impulse responses. Both are exported as SOFA files, a format for spatial acoustic data.

Downloads and support

Get the macOS or Windows app from the download section. The installers bundle Python, the Mesh2PPM models, and the simulation tools. The release page has checksums and previous versions.

For code, issue reports, and release notes, visit the Pinna2HRTF GitHub repository.
