📘 USER GUIDE

From pinna meshes to spatial audio.

Pinna2HRTF prepares one or two ear meshes, builds an acoustic simulation, and exports individualized HRTF and HRIR data in SOFA files.

Release status

This guide describes the current app and CLI work being prepared for the 1.5 release, including full-head scan preparation, reviewed ear edits, project organization, and pipeline controls. The public download links still point to v1.1.0; the 1.5 release has not been published yet.

Workflow at a glance

  1. Choose geometry. Import one or both pinna meshes, or prepare ears from an edited full-head scan.
  2. Review the inputs. Inspect mesh orientation and, for prepared scans, check each automatically extracted ear and save any manual edits.
  3. Prepare the simulation. Set the evaluation grid and frequency range, then run preprocessing.
  4. Solve and export. Run NumCalc locally or through Slurm, then write HRTF and HRIR results to SOFA.

Downloads and support

Get the macOS or Windows app from the download section. The installers bundle Python, the models, and simulation tools. The release page has checksums and previous versions.

For code, issue reports, and release notes, visit the Pinna2HRTF GitHub repository.
