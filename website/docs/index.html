USER GUIDE

Make your first HRTF.

Pinna2HRTF prepares one or two ear meshes, builds an acoustic simulation, and exports individualized HRTF and HRIR data in SOFA files.

Release status

This guide describes the current app and CLI source for version 2.0, including full-head scan preparation, reviewed ear edits, project organization, and pipeline controls. The public download links still point to v1.1.0; features in this source guide may not be available in that installer.

Before you start

You need one or two ear meshes, a project folder for generated files, and a choice of source directions and frequency range. For a full-head scan, first align the scan and review the extracted ears. Left and right always refer to the person being modeled.

Your first run

  1. Create a project. Choose where to save it and add your ear meshes. If you have a full-head scan, follow scan preparation first.
  2. Inspect the geometry. Check the selected ears and their orientation in Preview. Mesh2PPM prediction is optional; start with your original meshes unless you intend to use predicted geometry.
  3. Prepare the simulation. Choose the evaluation grid and frequency range in Project Settings, then run Preprocessing. Inspect the resulting geometry and source placement before starting NumCalc.
  4. Solve. Run NumCalc and follow progress in the live log. Use the technical log to investigate errors.
  5. Export. Run SOFA export and postprocessing after the simulation completes. Keep the project configuration with the results so you can identify how they were produced.

What you get

HRTFs describe the frequency response for each source direction. HRIRs describe the corresponding impulse responses. Both are exported in SOFA, a format for spatial acoustic data.

Find the right guide

Desktop app walks through a project, from installation to results. Python CLI covers repeatable runs from YAML. Build from source is for packaging the app yourself.

Downloads and support

Get the macOS or Windows app from the download section. The installers bundle Python, the models, and simulation tools. The release page has checksums and previous versions.
