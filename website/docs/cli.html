🐍 PYTHON CLI

Run the pipeline from a terminal.

The CLI exposes scan preparation, optional Mesh2PPM inference, simulation preprocessing, NumCalc, and postprocessing. Run individual stages or drive them from one YAML configuration.

Install the Python environment

Install Git and uv, then clone the repository and create the locked Python 3.11 environment:

git clone https://github.com/Any2HRTF/Pinna2HRTF.git
cd Pinna2HRTF
uv sync --locked --python 3.11

Prepare the external native tools once:

# macOS or Linux
bash Scripts/prepare_external_tools.sh
# Windows PowerShell
.\Scripts\prepare_windows_external_tools.ps1

The setup scripts download and build native dependencies. macOS requires Xcode Command Line Tools. Linux requires a C/C++ toolchain, Make, and the system libraries needed by Blender bpy. The Windows script installs MSYS2 if it is not already available.

For help, run uv run Pinna2HRTF --help or add --help to a subcommand.

Available stages

CommandPurposeTypical inputs / outputs
scan-preparationExtract and validate selected ears from a full-head scan.Scan path and crop rotation; creates Prepared/ ear meshes and report.
inferenceOptionally run Mesh2PPM to predict ear geometry.Ear STL meshes; writes predictions under Intermediates/.
preprocessingBuild the Mesh2HRTF simulation project.One or two ear meshes; creates Projects/.
numcalcSolve the acoustic simulation locally or through Slurm.Prepared simulation project and NumCalc runtime.
sofaExport HRTF and HRIR data from a Mesh2HRTF simulation project to SOFA files.One or two completed simulation projects and an output directory.
postprocessingNormalize simulation output and optionally resample HRIRs.Writes processed SOFA files to the configured output directory.
run-configRun configured stages in sequence or create a YAML template.Configuration file; stages selected with --stage.

Configure a run

Create a complete configuration template:

uv run Pinna2HRTF run-config --write-template pinna2hrtf.yaml

Edit input paths, output directory, external tool locations, evaluation grid, frequency range, and stage settings. Relative paths resolve from the YAML file’s directory. Set an unused ear to null. Mesh2PPM inference is disabled in the template, and preprocessing uses original meshes unless inference.use_predictions_for_preprocessing is set to true.

Run all enabled stages in order, or select a stage explicitly:

uv run Pinna2HRTF run-config --config pinna2hrtf.yaml --stage all
uv run Pinna2HRTF preprocessing --config pinna2hrtf.yaml
uv run Pinna2HRTF numcalc --config pinna2hrtf.yaml

Run multiple selected stages by repeating --stage. An explicitly selected stage runs even when its YAML enabled value is false. Add --dry-run to inspect a config-based run without executing the stages. YAML runs write left and right simulation projects under Projects/Left and Projects/Right in the output folder.

Postprocessing defaults

YAML postprocessing normalizes output with a −30 dB level offset and replaces its output folder by default. Set postprocessing.normalize: false to skip normalization, postprocessing.overwrite: false to preserve an existing output folder, or postprocessing.resample_hrirs: true to resample HRIR files. Resampling defaults to 48,000 Hz. It changes HRIRs only; HRTF files are not resampled. Direct SOFA commands without a YAML config do not apply the level offset.

Slurm

Set numcalc.mode: slurm and configure the cluster partition, QoS, memory, time limit, and array concurrency in the YAML file. The Slurm worker skips existing frequency output folders; remove incomplete step folders before resubmitting.

Scan preparation from YAML

Enable scan_preparation, choose a scan and explicit crop rotation, and select the ears. The scan guide explains alignment, orientation checks, manual review, and provenance.

scan_preparation:
  enabled: true
  scan_path: /path/to/edited-head.stl
  rotation_degrees: 0
  prepare_left: true
  prepare_right: true
  target_edge_mm: 0.75
  require_manual_review: false
  reviewed_left: null
  reviewed_right: null

Run individual stages without YAML

Every stage supports command-line options; inspect the current option list with its help flag. For example:

uv run Pinna2HRTF scan-preparation --help
uv run Pinna2HRTF preprocessing --help
uv run Pinna2HRTF numcalc --help

Keep a separate output folder for each experiment and inspect the geometry and source placement after preprocessing before starting a long simulation.
